1. Env Set Up

🧰 1.1 Prerequisites

Make sure you have the following installed:

  • Python 3.12+
  • Git
  • (Recommended) Make
  • (Recommended) uv

Option A — ⚡ Recommended Setup Using Make (Fully Automated)

make install will:

  • create virtual environment
  • install dependencies
  • install dev dependencies
  • install pre-commit hooks
📦 Install Make

macOS

brew install make
⚡ Install uv:
$ curl -LsSf https://astral.sh/uv/install.sh | sh

check installation

$ uv --version
uv 0.6.12 (e4e03833f 2025-04-02)
One-step setup
git clone <repo>
cd dwa-dv-generator
make install
⚙️ Available Make Commands

make install # create venv + install deps
make lint # run ruff + sqlfluff
make format # format python + sql
make test # run tests
make clean # remove venv and caches

Option B — Manual Setup Using uv

🐍 Create virtual environment

From the project root:

uv venv

Activate it:
- (macOS / Linux)

source .venv/bin/activate
Install project dependencies

Install dependencies from pyproject.toml:

uv pip install -e .

Install development dependencies:

uv pip install -e ".[dev]"
🔧 Install pre-commit hooks

This ensures formatting and linting before every commit.

pre-commit install

You can run manually:

pre-commit run --all-files

If a new dipendecy is added to the toml file you can run:

uv sync

Option C — Classic pip (fallback)

python -m venv .venv
source .venv/bin/activate
pip install -e ".[dev]"
pre-commit install
